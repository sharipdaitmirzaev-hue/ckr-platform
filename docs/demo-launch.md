# Демонстрационный запуск ЦКР

Этап 18: подготовка платформы к показу инвесторам, партнёрам и первым пользователям.

---

## 1. Запуск demo

```bash
cp .env.example .env.local
# заполните Supabase при необходимости

# Включить баннер и строгий demo-режим
NEXT_PUBLIC_DEMO_MODE=true

npm run dev
```

Откройте:

- `/` — главная
- `/demo` — правила демонстрации
- `/projects`, `/opportunities`, `/investments`, `/experts` — каталоги без регистрации

### Demo mode

| Открыто | Скрыто |
|---|---|
| Каталоги проектов / возможностей / инвестиций / экспертов | Телефоны и контакты |
| Публичные карточки | Документы |
| Лия (навигатор) | Переписка / сообщения |
| | Кабинет проекта и сделки |

Имена владельцев для гостей и в demo mode маскируются как **«Участник ЦКР»**.

## 2. Seed

### Встроенный fallback (без БД)

Данные в `src/lib/demo/seed-data.ts` автоматически подставляются в каталоги, если:

- нет Supabase env, или
- опубликованных записей в БД нет  
  (и `DEMO_CATALOG_FALLBACK` не выставлен в `false`).

Состав:

**Проекты:** гостиница у моря · производство воды · агро · IT  
**Возможности:** участок · помещение · оборудование · готовый бизнес  
**Инвестиции:** 10 млн · 50 млн  
**Эксперты:** юрист · бухгалтер · маркетолог · инженер  

Все профили вымышленные — без реальных ПДн.

### Запись в Supabase

```bash
# .env.local
SUPABASE_SERVICE_ROLE_KEY=...
DEMO_SEED_SECRET=long-random-secret

curl -X POST http://localhost:3000/api/demo/seed \
  -H "x-demo-seed-secret: $DEMO_SEED_SECRET"
```

Создаёт `demo.owner@ckr.local` и demo-экспертов с паролем `DemoCkrLaunch-ChangeMe!` — **смените после показа**.

Код: `src/lib/demo/apply-seed.ts`.

## 3. Онбординг

После регистрации `/onboarding`:

1. Выбор роли: предприниматель / инвестор / эксперт / компания  
2. Персональный путь:
   - предприниматель → `/lia`
   - инвестор → `/projects`
   - эксперт → `/dashboard/expert`
   - компания → `/dashboard/projects/create`

---

## 4. Тестовые сценарии показа

### Сценарий A — гость (30 секунд)

1. Главная: слоган и CTA  
2. `/projects` → карточка гостиницы  
3. `/opportunities` → участок  
4. `/investments` → 50 млн  
5. `/experts` → юрист  
6. Попытка отклика → регистрация  

### Сценарий B — предприниматель

1. Регистрация → онбординг → роль предприниматель  
2. Редирект в Лию → создать проект  
3. Кабинет проекта / workspace  

### Сценарий C — инвестор

1. Онбординг → инвестор  
2. Каталог проектов → заявка  

### Сценарий D — эксперт

1. Онбординг → эксперт  
2. `/dashboard/expert` → профиль
