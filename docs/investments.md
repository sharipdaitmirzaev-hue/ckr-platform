# Модуль «Инвестиции» — ЦКР

## Роль инвестора

Инвестор — отдельный тип участника платформы.

Он может:

- указать инвестиционные интересы;
- создавать инвестиционные предложения;
- находить проекты;
- отправлять и получать заявки через модуль `applications`.

Инвестиционное предложение — это не объявление «куплю что угодно», а структурированный интерес капитала в экосистеме ЦКР.

---

## Типы участия (`investment_type`)

| Тип | Смысл |
|---|---|
| `equity` | Доля в проекте / компании |
| `loan` | Займ |
| `partnership` | Партнёрство |
| `purchase` | Покупка актива / бизнеса |

---

## Статусы

| Статус | Смысл |
|---|---|
| `draft` | Черновик |
| `moderation` | На проверке |
| `published` | В каталоге `/investments` |
| `closed` | Закрыто, скрыто из каталога |

---

## Структура `investment_offers`

| Поле | Описание |
|---|---|
| `owner_id` | Инвестор |
| `title` / `description` | Суть предложения |
| `amount_min` / `amount_max` | Диапазон суммы |
| `currency` | Валюта |
| `regions` | Регионы интересов (`text[]`) |
| `categories` | Отрасли (slug категорий проектов) |
| `investment_type` | Тип участия |
| `status` | Статус публикации |

---

## Связь с проектами

1. На странице проекта блок **«Подходит инвесторам»** показывает релевантные `published` предложения (пересечение по сумме, отрасли, региону).  
2. Кнопка **«Предложить инвестицию»** создаёт заявку `applications` с `target_type = project`.  
3. На карточке инвестиции кнопка **«Отправить предложение инвестору»** создаёт заявку с `target_type = investment`.  

Таким образом: `investment_offers ↔ applications ↔ projects`.

## RLS

- Инвестор: create / update / delete своих предложений  
- Гости: только `status = published`  

Helpers заявок (`owns_application_target`, `get_application_target_owner`) обновлены для `investment`.
