# Справочный центр ЦКР

Краткая помощь для публичного запуска. Версия: `0.40.0-beta` · См. также: [public-launch-checklist.md](./public-launch-checklist.md) · [user-flows.md](./user-flows.md)

---

## Что такое ЦКР

**ЦКР — Центр комплексных решений.** Платформа, где предприниматели, инвесторы, эксперты и организации собирают проекты, находят ресурсы и доводят идеи до реализации.

Логика: **Идея → анализ → поиск ресурсов → партнёры → реализация.**

Лия — ИИ-навигатор: помогает выбрать путь и собрать черновик, но **не** действует без вашего подтверждения.

Старт: регистрация → выбор роли → профиль → первое действие.

## Как создать проект

1. Зарегистрируйтесь и выберите роль **предприниматель** (или компания).  
2. Откройте [Лию](/lia) и сценарий «Помоги создать бизнес-проект» / «От идеи до проекта».  
3. Ответьте на короткие вопросы — получите `ProjectDraft`.  
4. Подтвердите создание: проект появится в кабинете со статусом draft.  
5. Дополните карточку, переведите в active и откройте workspace для этапов.

Альтернатива: `/dashboard/projects/new` — ручное создание без мастера Лии.

Подсказка: не останавливайтесь после профиля — создание первого проекта даёт основную ценность.

## Как работает Лия

- Диалоги на `/lia` и виджет в кабинете.  
- Сценарии: идея → проект, поиск инвестиций / площадок / экспертов, аудит, стратегия, прогресс, результат.  
- Для новых пользователей: **«Как начать работу с ЦКР?»** → отчёт `LaunchGuide` (роль + первый шаг).  
- Лия читает каталоги и рекомендует; заявки, сделки и изменения данных — только с вашего согласия.  
- Внешние источники помечаются отдельно и не считаются проверенными автоматически.

Подробнее: [lia.md](./lia.md).

## Как найти инвестора

1. Оформите проект с понятным summary, регионом и потребностью в инвестициях.  
2. В Лие: «Найди инвестиционные предложения» или просмотрите каталог `/investments`.  
3. Отметьте интерес к подходящим предложениям и/или отправьте заявку владельцу.  
4. Ведите диалог и сделку в workspace — не переходите сразу к юридическим обещаниям вне платформы.

Инвестору наоборот: каталог `/projects` → интерес → заявка / сделка.

---

## Как стать экспертом

1. При онбординге выберите роль **эксперт**.  
2. Откройте `/dashboard/expert` и заполните компетенции, регион, краткое описание.  
3. Опубликуйте профиль в каталоге доверия.  
4. Отвечайте на заявки от проектов; фиксируйте результат в сделке / репутации.

Предпринимателю: сценарий Лии «Подбери эксперта» или каталог экспертов.
