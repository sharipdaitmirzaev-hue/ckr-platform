# Roadmap после ЦКР 1.0

Документ фиксирует направления **после** закрытого пилота / упаковки 1.0.  
**Не входит в текущую версию** `0.35.0-beta`.

Связано: [ckr-1.0-overview.md](./ckr-1.0-overview.md) · [roadmap.md](./roadmap.md)

---

## После запуска

### Улучшения Лии

- Более глубокий контекст проекта и CRM в сценариях  
- Кнопки «применить рекомендацию» с явным Confirm  
- Качество внешнего поиска и доверия к источникам  
- Мультиязычность / региональные подсказки

### Новые интеграции

- Банки и финтех-партнёры  
- Госуслуги / открытые реестры (осторожно, compliance)  
- Календари и мессенджеры для операторов  
- Экспорт документов (без обязательной генерации в 1.0)

### Платежи

- Боевой провайдер (ЮKassa / CloudPayments)  
- Подписки и комиссии по сделкам  
- Счета и акты для организаций

### Масштабирование

- API для мобильного приложения  
- Мультирегиональные кабинеты и SLA  
- Расширенные CRM-сегменты и org↔CRM связи  
- Нагрузка, мониторинг, observability production  
- Открытый доступ после стабилизации closed pilot

---

## Принцип приоритизации

1. Обратная связь пилота ТИНДА и операторов.  
2. Надёжность и доверие важнее новых модулей.  
3. Не плодить сущности БД без сценария использования.  
4. Лия остаётся навигатором, не автономным агентом решений.
