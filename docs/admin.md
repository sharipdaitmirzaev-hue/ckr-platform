# Административная панель ЦКР

## Роль администратора

Администратор — оператор платформы. Он не заменяет участников рынка, а обеспечивает доверие и порядок:

- модерирует публикации;
- проверяет документы и сущности;
- управляет ролями и доступом пользователей;
- блокирует нарушителей.

Роль: `user_roles.role = 'admin'`.

Назначение (только через БД / другого admin):

```sql
insert into public.user_roles (user_id, role)
values ('USER_UUID', 'admin');
```

---

## Доступ и безопасность

| Слой | Правило |
|---|---|
| Middleware | `/admin/*` только для авторизованных; проверка `role=admin`; блокированные пользователи разлогиниваются |
| Layout | `requireAdmin()` — повторная проверка роли |
| RLS | `public.is_admin(auth.uid())` на profiles, проектах, возможностях, инвестициях, экспертах, документах, заявках |

Заблокированный профиль (`profiles.is_blocked = true`) не может пользоваться защищёнными разделами.

## Процессы модерации

### Публикация сущности

1. Участник создаёт объект (`draft` / `moderation`).  
2. Админ в соответствующем разделе меняет `status` (`published` / `archived` / `closed`).  
3. При необходимости выставляет `verification_status`.

### Проверка доверия

1. Участник загружает документы и отправляет `verification_requests`.  
2. Админ открывает `/admin/verifications`.  
3. Просматривает документы, подтверждает или отклоняет.  
4. Цель получает `verified` / `unverified`.

### Пользователи

1. Поиск по имени / компании / городу / телефону.  
2. Просмотр профиля.  
3. Управление ролями (включая `admin`).  
4. Блокировка / разблокировка.
