# Продукт ЦКР

## Цель

**ЦКР — Центр комплексных решений** — цифровая бизнес-платформа, которая соединяет предпринимателей, инвесторов, владельцев активов и экспертов.

ЦКР помогает идеям находить капитал и ресурсы, а капиталу и активам — перспективные проекты.

Это не доска объявлений.  
Это платформа для поиска возможностей, партнёров и **комплексной реализации** бизнес-задач.

**Слоган:** Партнёрство. Надёжность. Результат.

---

## Принцип работы

```text
Идея → Анализ → Решения → Ресурсы → Реализация
```

| Этап | Смысл |
|---|---|
| Идея | Пользователь формулирует бизнес-замысел или проект |
| Анализ | Оценка задачи, потребностей, рисков и направлений |
| Решения | Подбор комплексного предложения под задачу |
| Ресурсы | Инвесторы, активы, специалисты, сопровождение |
| Реализация | Заявки, партнёрства и движение к результату |

ИИ-навигатор **Лия** в будущем сопровождает этот путь: помогает создать проект, проанализировать идею, подобрать ресурсы и решения.

---

## Роли пользователей

| Роль | Назначение |
|---|---|
| Предприниматель | Создаёт проекты, ищет ресурсы, партнёров и решения |
| Инвестор | Ищет проекты, формирует предложения, отправляет заявки |
| Эксперт | Юристы, бухгалтеры, маркетологи и другие специалисты |
| Компания | Представляет организацию, активы и комплексные возможности |
| Администратор | Модерация, управление платформой |

Пользователь может иметь несколько ролей.

## Основные модули

### Проекты
Описание бизнес-идеи, требуемые инвестиции, регион, поиск партнёров.

### Возможности
Земля, помещения, оборудование, готовый бизнес, технологии.

### Решения
Комплексные предложения:
- поиск инвестора;
- поиск земли;
- поиск оборудования;
- поиск специалистов;
- юридическое сопровождение;
- маркетинг.

### Инвестиции
Предложения инвесторов, поиск проектов, заявки.

### Эксперты
Профили специалистов и отклики на задачи.

### Личный кабинет (`/dashboard`)
Мои проекты, заявки, сообщения, избранное, документы.

### Лия
ИИ-навигатор платформы (интеграция на отдельном этапе).
