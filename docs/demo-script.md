# Demo-сценарий ЦКР 1.0

Этап 35 · Демонстрация партнёрам и закрытому пилоту.

Связано: [tinda-pilot.md](./tinda-pilot.md) · [user-flows.md](./user-flows.md) · [demo-launch.md](./demo-launch.md)

**Пример кейса:** ООО ТИНДА — развитие оптовой B2B-платформы.

---

## Подготовка (5 минут)

1. Применить миграции.  
2. Включить `NEXT_PUBLIC_DEMO_MODE=true` (при необходимости demo catalog fallback).  
3. Опционально: `npm run seed:tinda` на стенде пилота.  
4. Открыть `/` и `/about` на большом экране.

Учётка пилота после seed: `pilot.tinda@ckr.local` (пароль сменить сразу).

---

## Сценарий демонстрации (~15–20 минут)

### 1. Пользователь приходит в ЦКР

- Главная `/` — бренд ЦКР, tagline, обещание.  
- Коротко: `/about` — путь «Идея → … → Реализация», роли, блок «Первый кейс — ТИНДА».  
- CTA: «Создать проект с Лией» → `/lia`.

### 2. Лия помогает создать проект

- Сценарий «Помоги создать бизнес-проект» или шаблон `business_development`.  
- Для ТИНДА: показать уже созданный проект «Развитие оптовой платформы ТИНДА».  
- Подчеркнуть: Лия рекомендует, создание — с подтверждением.

### 3. Проект получает анализ

- Workspace / карточка → «Анализ Лией».  
- Показать available / missing / recommendations / risks.  
- Опционально: «Аудит бизнеса» или «Разработать стратегию развития».

### 4. Находятся решения

- `find_solutions` или каталоги `/opportunities`, `/investments`, `/experts`.  
- Связать с CRM-сегментами ТИНДА (клиенты / поставщики / партнёры) в `/admin/crm`.

### 5. Создаётся взаимодействие

- Заявка → принятие → сделка `negotiation`.  
- Участники сделки в workspace.  
- Инвесторский путь: интерес («Интересно») → заявка.

### 6. Проект сопровождается

- Workspace: milestones, ProjectProgress (roadmap, задачи, KPI).  
- Outcomes: цель → текущее → факт; панель `/admin/results`.  
- Лия: «Проверь прогресс» / «Оцени результат проекта».

## Сообщения для аудитории

1. ЦКР ведёт **путь**, а не список объявлений.  
2. Лия **не заменяет** решение человека.  
3. ТИНДА — **первый реальный контур** пилота на существующих модулях.  
4. 1.0 готов к **закрытому пилоту**, не к массовому открытию без ограничений.
