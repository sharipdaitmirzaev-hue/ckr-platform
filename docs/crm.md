# CRM ЦКР

Этап 21: внутренняя система работы команды ЦКР с клиентами, партнёрами и потенциальными проектами.

Доступ: только администраторы (`/admin/crm`).

---

## 1. Назначение

CRM не заменяет публичную платформу. Это рабочее место оператора:

- фиксировать контакты и источники;
- вести лиды до сделки или закрытия;
- планировать задачи и историю коммуникаций;
- конвертировать лид в сущности платформы — только после подтверждения.

---

## 2. Контакты — `crm_contacts`

| Поле | Описание |
|---|---|
| name | Имя |
| company_name | Компания |
| phone / email | Связь |
| type | entrepreneur · investor · expert · company · partner · other |
| source | Откуда пришёл контакт |
| assigned_to | Ответственный оператор |
| status | new · active · inactive |
| notes | Заметки |
| linked_user_id | Связь с профилем платформы (если есть) |

RLS: полный доступ только `is_admin`.

---

## 3. Лиды — `leads`

| Поле | Описание |
|---|---|
| contact_id | Связанный контакт |
| title / description | Суть потенциального проекта / сделки |
| category | Отрасль / категория |
| assigned_to | Ответственный |
| stage | new → contacted → qualified → project_created → deal → closed |
| converted_* | ID созданных сущностей после конвертации |

Карточка: `/admin/crm/leads/[id]`.

---

## 4. Dashboard `/admin/crm`

Разделы (вкладки):

| Раздел | Содержание |
|---|---|
| Контакты | Создание и статусы |
| Лиды | Создание, этапы, ссылка на карточку |
| Задачи | Активности типа task + завершение |
| История | Лента звонков, встреч, писем, комментариев, задач |

Сводка сверху: число контактов, открытых лидов, открытых задач, активностей.

---

## 5. Конвертация

На карточке лида — форма конвертации. **Обязателен checkbox подтверждения администратора.**

| Цель | Результат |
|---|---|
| Лид → Пользователь | beta-invite по email контакта (и связь, если профиль найден) |
| Лид → Проект | черновик `projects` |
| Лид → Возможность | черновик `opportunities` |
| Лид → Инвестиция | черновик `investment_offers` |

После конвертации пишется запись в `crm_activities` и обновляются поля `converted_*` / этап лида.

Без подтверждения действие не выполняется.

---

## 6. Активности — `crm_activities`

Типы:

- call — звонок;
- meeting — встреча;
- email — письмо;
- comment — комментарий;
- task — задача (`task_status`: open · done · cancelled, опционально `due_at`).

Привязка: `contact_id` и/или `lead_id` (хотя бы одно обязательно).

---

## 7. Лия для оператора (архитектура)

Подготовка в `src/lib/crm/lia-operator.ts`:

- сценарии и примеры запросов («Какие лиды требуют внимания?», «Какие проекты сейчас без инвестора?»);
- disclaimer: Лия рекомендует, не действует за администратора;
- черновой insight по лидам на ранних этапах на `/admin/crm`.

Полный чат-движок и ответы по каталогу проектов — следующие итерации. Конвертации и изменения сущностей остаются только за админом с подтверждением.

---

## 8. Шаблоны сегментов (этап 31)

По итогам пилота ТИНДА: `customers` · `suppliers` · `partners`.

- Конфиг: `src/config/crm-templates.ts`
- UI: `/admin/crm` (вкладка контакты) — применение с confirm
- Action: `applyCrmSegmentTemplateAction`

Шаблоны создают контакт-сегмент без реальных ПДн; дальше оператор наполняет аккаунты вручную.

## 9. Принципы ЦКР

- Спокойный операторский интерфейс в фирменных токенах.
- Публичная карточка ≠ приватный кабинет ≠ CRM.
- Лия только рекомендует.
- Нет автосоздания сущностей без подтверждения администратора.
