## Зачем этот кейс

ООО ТИНДА — первый эталонный путь **Project Acquisition**: как бизнес-задача превращается в проект экосистемы ЦКР и получает развитие.

Не новый каталог — используются existing `projects`, `crm`, `lia`, `organizations`.

---

## Путь

```
Бизнес-задача
    ↓
Анализ
    ↓
Проект
    ↓
Ресурсы
    ↓
Развитие
```

### 1. Бизнес-задача

Оптовая торговая компания (Амурская область / Тында) развивает B2B-платформу закупок и поставок. Нужно упаковать действующий бизнес как проект развития, найти партнёров и ресурсы.

Источник: `tinda` / пилот / кейс.

### 2. Анализ

- Лия: сценарий **«Аудит моего бизнеса»** → `BusinessAuditReport`
- При необходимости: **«Разработать стратегию развития»** → `StrategyReport`
- SWOT, цели на 6–12 месяцев, ограничения роста

Создание проекта **только после подтверждения** предпринимателя / оператора.

### 3. Проект

- Шаблон: `business_development`
- Статус: `draft` → `moderation` → `published` / `active`
- CRM: лид `new` → `contacted` → `qualified` → `project_created`
- Pipeline: `lead_found` → … → `active`

### 4. Ресурсы

- `opportunities` — помещения, поставки, инфраструктура
- `investments` — капитал на масштабирование
- workspace: этапы подготовки → продажи → партнёры → масштаб

### 5. Развитие

- эксперты, партнёры (`organizations`), заявки, сделки
- feedback → улучшения продукта
- повторный цикл качества (`ProjectQualityScore`)

---

## Связь с воронкой acquisition

| Этап кейса | Pipeline |
|---|---|
| Задача зафиксирована в CRM | `lead_found` / `contacted` |
| Интерес подтверждён | `interested` |
| Карточка создана | `draft_created` |
| Модерация / публикация | `moderation` / `published` |
| Заявки и партнёры | `active` |

---

## Метрики успеха кейса

- лид → проект без потери контекста;
- качество карточки ≥ medium перед публикацией;
- есть хотя бы один ресурсный или партнёрский контур;
- кейс воспроизводим для других предпринимателей через публичный аудит Лии.

---

## Как повторить

1. `/lia?scenario=business_audit` — аудит.
2. Подтвердить создание проекта (шаблон development).
3. `/lia?scenario=develop_strategy` — стратегия.
4. Заполнить ресурсы и опубликовать.
5. Смотреть поток на `/admin/project-acquisition`.
