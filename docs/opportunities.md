# Модуль «Возможности» — ЦКР

## Роль в платформе

**Возможность** — любой ресурс, который пользователь предлагает для реализации проектов.

Логика ЦКР:

```text
Проект → Возможность → Партнёр → Реализация
```

Примеры возможностей:

- земельный участок;
- производственное помещение;
- оборудование;
- готовый бизнес;
- технология;
- услуга;
- партнёрство.

Возможность — не товарное объявление, а ресурсная карточка в экосистеме ЦКР.

---

## Связь с проектами

| Сущность | Роль |
|---|---|
| Проект | Центральная задача / бизнес-замысел |
| Возможность | Ресурс, который закрывает потребность проекта |
| Партнёр | Владелец возможности или участник сделки |
| Реализация | Результат связки проекта и ресурса |

В следующих этапах появятся явные связи (заявки, matching, решения). На Этапе 3 заложен независимый каталог возможностей с тем же контуром публикации, что у проектов.

## Структура `opportunities`

| Поле | Тип | Описание |
|---|---|---|
| `id` | uuid | PK |
| `owner_id` | uuid | Владелец → `profiles.id` |
| `title` | text | Название |
| `description` | text | Описание |
| `type` | text | Slug типа → `opportunity_categories.slug` |
| `region` | text | Регион |
| `city` | text | Город |
| `price` | numeric | Стоимость (nullable = по запросу) |
| `currency` | text | Валюта |
| `status` | enum | Статус публикации |
| `created_at` / `updated_at` | timestamptz | Служебные |

| `partner` | Партнёры |

---

## Статусы

| Статус | Смысл |
|---|---|
| `draft` | Черновик, только владелец |
| `moderation` | На проверке |
| `published` | В публичном каталоге `/opportunities` |
| `archived` | Скрыта из каталога |

Публикация: владелец меняет статус на `published` (или `moderation` для будущей админ-проверки).

---

## RLS

- Владелец: create / read / update / delete своих записей  
- Гость и другие: только `status = published`  
- Admin: полный доступ  

Категории: публичное чтение.
