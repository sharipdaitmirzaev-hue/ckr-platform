# Public Beta → Public Launch Plan

План перехода ЦКР из Open Beta к полноценному публичному запуску.

Связано: [public-launch-decision.md](./public-launch-decision.md) · [open-beta-launch-control.md](./open-beta-launch-control.md) · [open-beta-growth.md](./open-beta-growth.md) · [open-beta-launch-plan.md](./open-beta-launch-plan.md)

Версия документа: этап 57 · `0.57.0-beta`

## Переход beta → public

1. **Decision Gate** — `/admin/public-launch-decision` → зафиксировать `public_launch` (или `continue_beta` / `improve_product`).
2. **Закрыть блокеры** — Critical = 0; Product / Business без `blocked`.
3. **Удержание** — D7 ≥ 25%, D30 ≥ 15% на когорте Open Beta (`/admin/open-beta-growth`).
4. **Экосистема** — подтвердить реальные связи (заявки / интересы / сделки).
5. **Коммуникация** — обновить публичные страницы ценности и кейс ТИНДА.
6. **Контроль доступа** — расширять signup постепенно; не снимать мониторинг сразу.
7. **Операции** — feedback → improvements остаётся обязательным циклом.

Что не делаем на переходе:

- не добавляем новые крупные бизнес-модули;
- не открываем анонимный массовый трафик без health/retention контроля;
- не меняем решение «вслепую» — только по данным Decision Gate.

## Первые 90 дней

| Дни | Фокус |
|---|---|
| 1–14 | Стабилизация public: Critical = 0, онбординг ролей, Лия, smoke ключевых путей |
| 15–30 | Рост когорты, качество matching, заявки и интересы, weekly retention review |
| 31–60 | Партнёры и организации, коммерческие сценарии, кейсы помимо ТИНДА |
| 61–90 | Оценка масштабирования: retention, экосистема, монетизация, следующий gate |

Ежедневно: Critical · активация · связи.  
Еженедельно: Growth + Public Launch Decision indicators.  
Ежемесячно: управленческий срез готовности и рисков.

## Контрольные показатели

### Продукт и стабильность

- Critical issues = 0 в проде  
- Health Open Beta / public ≠ `critical`  
- Основные сценарии проходимы end-to-end  

### Пользователи

- Регистрация и активация растут без обвала D7/D30  
- D7 ≥ 25%, D30 ≥ 15% (ориентир масштабирования)  
- ≥35% используют Лию или создают первый объект  

### Экосистема

- Рост проектов / экспертов / инвесторов / организаций  
- Заявки и интересы между ролями  
- Сделки / партнёрства как сигнал реальной ценности  

### Бизнес

- Понятная ценность на публичных страницах  
- Кейс ТИНДА + новые истории  
- Партнёры готовы; модель монетизации описана
