## Контрольные контуры

| Контур | Где смотреть | Что контролируем |
|---|---|---|
| Активность команды | `/admin/pilot`, workspace | обновления проекта, `project_activity`, статусы участников |

## Еженедельный ритм оператора

1. Открыть `/admin/pilot` — участники / проекты / активность.  
2. Сверить воронку `/admin/pilot/report`.  
3. Запустить Лию: «Что мешает проекту двигаться?» (`pilot_insight`).  
4. Обновить KPI и статусы этапов roadmap в workspace ТИНДА.  
5. Собрать feedback (категория + приоритет).  
6. Закрыть или эскалировать `pilot_issues`.

---

## Критерии прогресса ТИНДА

- Команда активна (обновления проекта < 14 дней).  
- Текущий этап roadmap не в `blocked`.  
- KPI имеют актуальные `current_value`.  
- Есть зафиксированные результаты или явный план их фиксации.  
- Feedback по UX / business_value / lia_quality собран минимум раз за спринт пилота.

Seed: `npm run seed:tinda` (версия seed meta v4: участник + чеклист).
