Связано: [first-users-launch.md](./first-users-launch.md) · [analytics.md](./analytics.md) · [controlled-beta / invites](./beta-launch.md) · [improvements](./product-improvement-loop.md)

## Цель

Провести **первый запуск ЦКР на ограниченной группе реальных пользователей** — без массового релиза и без новых крупных бизнес-модулей.

Фокус: приглашения → сценарии → feedback → анализ поведения.

## Кого приглашаем

| Роль | Кол-во | Что проверяем |
|---|---|---|
| Предприниматели | 5–10 | регистрация, роль, профиль, Лия, проект |
| Эксперты | 2–3 | профиль, компетенции, запросы |
| Инвесторы | 1–2 | просмотр проектов, интерес, взаимодействие |
| Организации | 1–3 | профиль, проекты, возможности |

Приглашения: `/admin/invites` → `beta_invites` с полями **роль**, **источник** (`first_users_wave` и др.), **статус**.

### Статусы приглашения

```text
invited → activated → active → completed
                         ↘ disabled
```

- `invited` — код создан / отправлен  
- `activated` — регистрация по коду  
- `active` — первый вход / участие  
- `completed` — сценарий роли завершён  
- `disabled` — отключён

## Пользовательский путь

```text
Регистрация → Роль → Профиль → Первое действие → Лия → Создание объекта
```

На дашборде для каждого участника: где остановился, сколько часов заняло, вопросы из feedback.

## Аналитика

События `analytics_events`:

| Событие | Когда |
|---|---|
| `invite_sent` | создание / отметка отправки invite |
| `invite_accepted` | регистрация по коду |
| `first_login` | первый вход |
| `profile_completed` | онбординг / профиль |
| `lia_first_used` | первое использование Лии |
| `project_created` | создание проекта |
| `expert_profile_created` | профиль эксперта |
| `investment_interest_created` | интерес инвестора |
| `feedback_sent` | обратная связь |

Плюс воронка этапа 49: `registration_*`, `role_selected`, `lia_started`, `first_object_created`.

## Feedback loop

Каждый участник может оставить в кабинете:

1. что понравилось;  
2. что непонятно;  
3. что мешает.  

Цепочка (существующая):

```text
feedback → pilot_issues → product_improvements
```

UI: `FirstUsersFeedbackPrompt` на `/dashboard` после первого действия · админ `/admin/improvements`.

---
