# Сценарий «От идеи до проекта»

Первый полноценный пользовательский путь ЦКР для участника без опыта.

## Путь

```text
Идея → Лия → Черновик (ProjectDraft) → Проект (draft) → Редактирование → Публикация
```

1. Пользователь открывает `/lia`.  
2. Выбирает быстрый сценарий **«Помоги создать бизнес-проект»**.  
3. Лия по шагам собирает данные.  
4. Формирует `ProjectDraft` и показывает предварительный проект.  
5. Пользователь нажимает **«Редактировать»** или **«Создать проект»**.  
6. Только после подтверждения создаётся запись в `projects` со статусом `draft`.  
7. Редирект на `/dashboard/projects/[id]/edit`.  
8. Далее пользователь дорабатывает карточку и публикует через обычный поток проектов (`moderation` / `published`).

---

## Что собирает Лия

| Поле | Смысл |
|---|---|
| `title` | Название идеи |
| `category` | Отрасль (slug категории) |
| `region` | Регион |
| `description` | Описание (+ что есть / что требуется) |
| `summary` | Краткое описание для каталога |
| `investment_required` | Сумма инвестиций |
| `stage` | Стадия: idea / startup / operating / expansion |

---

## UI-компоненты

| Компонент | Назначение |
|---|---|
| `LiaProjectFlow` | Оркестрация preview → edit → create |
| `ProjectDraftPreview` | Карточка предварительного проекта |
| `ProjectCreationWizard` | Редактирование черновика до сохранения |

Стиль — корпоративный ЦКР (surface cards, accent badges, без лишних декораций).

---

## Безопасность

- Лия **не** создаёт проект автоматически.  
- Запись в БД только через `createProjectFromLiaDraftAction` после кнопки «Создать проект».  
- Статус при создании всегда `draft`.  
- Требуется авторизация.  
- Ответы Лии остаются предварительными рекомендациями.
