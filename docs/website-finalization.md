# Website Finalization & UX (этап 67)

Публичный сайт ЦКР приведён к состоянию готового продукта для предпринимателя, партнёра или инвестора. Новые бизнес-модули и админ-разделы не добавлялись.

Версия: **0.67.0-beta**. Конфиг: `src/config/website-final.ts`.

---

| Путь | Назначение |
|------|------------|

Единые shell: `SiteHeader`, `SiteFooter`, кнопки `ButtonLink`, карточки каталогов, блок следующего шага `PageNextStep`.

## Пользовательские сценарии

### Главный путь

Посетитель → понимает ЦКР → выбирает задачу.

CTA на главной (`HOME_INTENT_CTAS`):

1. **У меня есть бизнес** → `/lia` (аудит)
2. **У меня есть идея** → `/lia` (идея)
3. **Мне нужны ресурсы** → `/opportunities`
4. **Я хочу стать партнёром** → `/organization`

### Регистрация без тупиков

Посетитель → Регистрация → Выбор роли → Создание профиля → Первое действие.

Каждая ключевая страница заканчивается блоком «Что сделать дальше» (`PAGE_NEXT_STEPS` / `RoleLanding.nextStep`).

### Лия

Основной CTA: **«Расскажите о вашей задаче»**.

После входа: **Аудит → Рекомендации → Создание проекта**.

### Роли

Страницы `/entrepreneur`, `/investor`, `/expert`, `/organization` отвечают:

- кому подходит;
- какая проблема решается;
- как работает ЦКР;
- что сделать дальше.

### Marketplace

Карточки `/projects`, `/investments`, `/opportunities`, `/experts`: описание, статус, кнопка действия.

### Доверие (`/trust`)

- как проверяются проекты;
- как работает ЦКР;
- принципы взаимодействия.

## Основные точки входа

| Вход | Куда ведёт |
|------|------------|
| Hero intent CTA | Лия / возможности / организация |
| Шапка | Проекты, возможности, инвестиции, эксперты, Лия, услуги |
| Мобильное меню | Полный список разделов + роли |
| Лия | Аудит и сценарии |
| Роли | Регистрация с `role` / `next` |
| Контакты | Форма обращения (`contact_started`) |
| Регистрация | `registration_started` → `registration_completed` |
