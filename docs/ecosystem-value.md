---

## Что такое ценность экосистемы

Ценность — не число регистраций, а цепочка:

```text
совпадение создано
    ↓
принято участниками
    ↓
началось взаимодействие
    ↓
получен результат (сделка / партнёрство / закрытая связь)
```

Если совпадения обрываются на заявке — ценность низкая. Если доходят до результата — экосистема работает.

---

## Как измерять связи

Типы (`EcosystemMatchingMetrics`):

| Тип | Источники |
|---|---|
| Проект → Эксперт | `applications` (expert), deals с ролью expert |
| Проект → Инвестор | заявки investment/project, interests, deals investor |
| Проект → Партнёр | заявки opportunity, partnerships, deals partnership |
| Организация → Проект | `projects.organization_id` |

По каждому типу:

- созданные связи  
- отправленные заявки  
- принятые  
- активные  
- завершённые  

---

## Как оценивать результат

`MatchQualityScore` (0–100) — эвристика конверсий воронки:

1. создано → принято  
2. принято → взаимодействие  
3. взаимодействие → результат  

На UI: слабые / сильные / успешные сценарии.  
**Только аналитика** — система не принимает решения и не меняет связи.

Лия: «Какая польза от экосистемы ЦКР?» → `EcosystemValueReport`.
